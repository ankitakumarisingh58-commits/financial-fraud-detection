# 💳 Financial Fraud Detection Dashboard

## Project Overview
Financial Fraud Detection is a data analytics and machine learning project designed to identify fraudulent financial transactions using historical transaction data.

## Features
- Interactive Financial Dashboard
- Fraud vs Genuine Transaction Analysis
- Transaction Amount Analysis
- Location-wise Fraud Detection
- Device and Card Analysis
- Machine Learning Prediction
- Dataset Filtering and Download

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Classifier
- Plotly
- Streamlit

## Dataset
The project uses a dataset containing 50,000 financial transaction records and 14 columns.

## Installation

Install the required libraries:

pip install -r requirements.txt

## Train Model

python train_model.py

## Run Dashboard

streamlit run app.py

## Project Objective
To analyse financial transactions, identify suspicious activities, and support fraud detection through interactive visualizations and machine learning.
